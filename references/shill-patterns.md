# 评论区水军与无效噪音识别清单

在提炼真实口碑与计算占比前，先按以下特征对原始评论做降权或剔除。

## 1. 通用高危水军特征（判定为无效噪音）

- **返现/任务话术**：“好评返现、客服小姐姐态度超好、物流很快第二天就到、包装严实没有破损、习惯性好评、为了凑字数”等，**0 有效产品信息**。
- **空洞形容词堆砌**：“质感绝了、闭眼冲、YYDS、太香了、物超所值、强烈推荐”，但全文找不到任何具体使用细节。
- **复制粘贴与模板化**：多条评论句式高度一致（如“1. 外观漂亮 2. 性能强劲 3. 客服耐心”），或直接复制商品详情页官方术语。

## 2. 分平台特殊套路

| 平台 | 常见水军 / 软广套路 | 真实高价值信号 |
| :--- | :--- | :--- |
| **淘宝 / 天猫 / 京东 / 拼多多** | “好评返现”凑字数小作文；默认好评；刚签收 1 小时内的五星好评 | **追加评论（30天以上）**、带实拍瑕疵图的**中评/3星**、“整体还行但……” |
| **小红书 / 抖音** | “无广纯分享”但评论区统一问链接 | 评论区里的**“拔草/踩雷返图”**、老用户吐槽翻车 |
| **Steam / 游戏** | “我是傻逼（0.2小时）”玩梗刷屏；水军刷情怀；**免费赠游鉴赏家/公关软广长文**（含“免费提供游戏 / 鉴赏家培训计划 / 点评小分队 / 加群引流”等利益相关声明） | **游玩 > 10 小时后的自购差评**、具体机制/优化长评 |
| **App Store / 软件** | 统一时间段刷出的短平快五星 | 1～3 星里吐槽**收费吃相、闪退、广告弹窗**的评价 |
| **大众点评 / 探店** | “打卡送甜品”换来的 5 星九宫格 | 吐槽**排队久、预制菜、分量缩水**的低分评价 |

## 3. 比例计算规则

- `水军浓度 = 无效噪音条数 / 总样本条数`
- **统一分母口径**：当有效真实样本 `>= 10` 条且可精确计数时，所有优点/缺点占比**统一以有效真实样本总数为分母**，并写明分子分母（如 `有效样本提及 11/47 条，占比 23%`）。
- **小样本兜底**：当有效样本 `< 10` 条或文本混杂无法精确计数时，**禁止输出百分比**，改用定性频率（`高频提及 / 中频提及 / 偶发提及`）。
- **防误判原则**：如果一条好评虽然简短，但提到了**具体使用细节**（如“充一次电用4天，就是线太短”），**不算水军**，计入有效样本。
